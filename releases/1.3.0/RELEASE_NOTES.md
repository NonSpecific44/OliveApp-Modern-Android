### Improved
- **Artists tab: one entry per artist.** The Olive lists its library by album, so each artist used to appear once for every album. Now each artist appears once, with their first album's cover and the number of albums (or the album's name if there's just one). Tap an artist to see all their albums, then tap an album for its tracks.
- The whole artist list loads in the background, so an artist's albums are never split across pages.

### Install
